

# DayWise: Daily Wellness and Productivity Tracker

## Overview

DayWise is a Java-based application designed to help individuals organize their daily routines and monitor basic wellness habits. It provides features for recording sleep schedules, reviewing sleep duration, managing daily activities, and accessing predefined meal and activity suggestions based on selected personal goals.

The system also allows users to create scheduled routines, set dates and times for activities, and mark completed tasks. It generates a daily summary of recorded sleep information and routine progress, helping users keep track of their everyday habits in one application.

## Key Features

- **User Profile Management** – Allows users to enter basic profile information, including age, height, and weight.
- **BMI Calculation** – Calculates Body Mass Index (BMI) using the provided height and weight for general reference.
- **Sleep Tracking** – Allows users to record their sleeping and waking times and calculates the total sleep duration, including schedules that cross midnight.
- **Sleep Information Feedback** – Provides informational feedback based on general sleep reference ranges.
- **Meal Suggestions** – Displays predefined meal suggestions based on the user's selected goal.
- **Activity Suggestions** – Provides predefined activity recommendations based on the selected goal.
- **Routine Scheduler** – Allows users to create daily routines by assigning dates and times to planned activities.
- **Routine Reminders** – Displays reminders while the application is running.
- **Task Completion Tracking** – Allows users to mark scheduled activities as completed.
- **Daily Summary** – Presents a summary of recorded sleep information and daily routine progress.

## Target Users

- **Students** – Individuals who want to organize their daily schedules and monitor their everyday habits.
- **Individuals Managing Daily Habits** – People who want a simple tool for tracking sleep schedules and daily activities.

## Technologies and Concepts

The system will be developed using Java and object-oriented programming principles.

- Java for application development.
- Classes and objects for organizing user profiles, routines, and wellness records.
- Encapsulation and abstraction for managing system data and operations.
- Methods for implementing calculations and application functionalities.
- Arrays or collections for storing user records and scheduled activities.
- Exception handling for managing invalid inputs and unexpected operations.
- Inheritance and polymorphism may be applied to organize different types of wellness suggestions.

## Limitations

- The system does not provide medical diagnosis, treatment, or professional nutritional advice.
- It does not generate fully personalized wellness plans or automatically adjust suggestions for specific dietary conditions.
- It does not integrate with wearable devices or external health-monitoring platforms.
- It does not support cloud synchronization or multi-user social features.
- Reminders are displayed only while the application is running and do not function as phone push notifications or closed-application reminders.
- It does not provide advanced health analytics, predictions, or guaranteed wellness outcomes.
